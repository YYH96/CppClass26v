# 형변환 (Casting)

형변환은 한 자료형의 값을 다른 자료형으로 바꾸는 일입니다. 컴퓨터는 자료형에 따라 같은 비트도 다르게 해석하므로, 변환 뒤에 값의 범위나 정밀도가 달라질 수 있습니다.

## 기본 자료형 변환

### 암시적 형변환

컴파일러가 비교적 자연스럽다고 판단해 자동으로 변환하는 방식입니다.

```cpp
int score = 95;
double average = score; // int -> double, 자동 변환
```

### 명시적 형변환

프로그래머가 변환 의도를 코드로 직접 적는 방식입니다.

```cpp
double ratio = 3.9;
int count = static_cast<int>(ratio); // 소수점 아래가 버려져 3
```

> !기억 - `double`에서 `int`로 변환할 때는 반올림이 아니라 소수점 아래가 버려집니다. 큰 정수를 작은 자료형에 넣거나, 부호 있는 값을 부호 없는 자료형으로 바꾸는 경우에도 값이 달라질 수 있습니다.

## C 스타일 형변환

```cpp
int count = (int)ratio;
```

짧게 쓸 수 있지만, 어떤 종류의 변환을 의도했는지 코드만 보고 알기 어렵습니다. C++에서는 특별한 이유가 없다면 C 스타일보다 아래의 C++ 캐스트를 사용합니다.

## C++ 형변환

| 문법 | 주 용도 | 주의점 |
| --- | --- | --- |
| `static_cast<T>(value)` | 숫자형, 열거형 등 일반적인 명시적 변환 | 범위·정밀도 손실은 여전히 확인해야 함 |
| `const_cast<T>(value)` | `const` 또는 `volatile` 속성 추가·제거 | 원래 `const` 객체를 수정하면 정의되지 않은 동작 |
| `reinterpret_cast<T>(value)` | 주소·비트 수준의 저수준 해석 | 자료형 안전성이 매우 낮고 플랫폼 의존적일 수 있음 |
| `dynamic_cast<T>(value)` | 상속 관계에서 실제 객체 타입을 안전하게 확인 | RTTI와 다형적 기반 클래스가 필요 |

## 권장 순서

1. 변환하지 않고 해결할 수 있는지 먼저 생각합니다.
2. 일반적인 숫자 변환은 `static_cast`를 사용합니다.
3. `const_cast`, `reinterpret_cast`는 왜 필요한지 설명할 수 있을 때만 사용합니다.
4. 상속 관계의 실제 타입 확인은 `dynamic_cast`와 RTTI 파일에서 다룹니다.

## RTTI란?

RTTI(Run-Time Type Information)는 프로그램 실행 중에 객체의 실제 자료형 정보를 확인하는 기능입니다.

- `typeid`: 현재 객체의 타입 정보를 확인
- `dynamic_cast`: 기반 클래스 포인터를 실제 파생 클래스 포인터로 안전하게 변환

RTTI는 `virtual` 함수가 있는 다형적 기반 클래스에서 가장 자연스럽게 사용됩니다. 상속과 가상 함수의 자세한 내용은 클래스 수업에서 다시 다룹니다.
