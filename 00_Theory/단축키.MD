# Visual Studio 코딩 단축키

코드를 작성할 때 자주 쓰는 Visual Studio 기본 단축키를 정리한다. `Ctrl+K, Ctrl+C`처럼 두 키 조합으로 표시된 단축키는 첫 번째 조합을 누른 뒤 손을 떼고 두 번째 조합을 누른다.

## 먼저 알아둘 점

`Ctrl+K, Ctrl+O`가 아니라 **`Ctrl+M, Ctrl+O`**가 코드 정의 접기 단축키다.

```text
Ctrl+M, Ctrl+O
```

함수의 구현을 접고 함수 이름(정의)만 빠르게 보고 싶을 때 사용한다.

## 코드 작성과 편집

| 단축키 | 기능 | 사용 예 |
| --- | --- | --- |
| `Enter` | 줄 바꾸기 | 현재 위치에서 다음 줄로 이동 |
| `Ctrl + Enter` | 현재 줄 위에 빈 줄 삽입 | 위에 변수 선언이나 주석을 추가할 때 |
| `Ctrl + D` | 현재 줄 또는 선택 영역 복제 | 비슷한 코드를 한 줄 복사해 수정할 때 |
| `Ctrl + L` | 현재 줄 잘라내기 | 필요 없는 줄을 빠르게 제거할 때. 실수하면 `Ctrl + Z` |
| `Tab` | 들여쓰기 또는 IntelliSense 항목 확정 | 코드 블록 들여쓰기, 추천 항목 선택 |
| `Shift + Tab` | 내어쓰기 | 선택한 코드 블록의 들여쓰기 줄이기 |
| `Ctrl + Space` | 코드 자동 완성 목록 열기 | 함수·변수 이름 추천을 다시 보고 싶을 때 |

## 주석 처리

먼저 여러 줄을 선택한 뒤 사용한다.

| 단축키 | 기능 |
| --- | --- |
| `Ctrl + K, Ctrl + C` | 선택 영역을 주석 처리 |
| `Ctrl + K, Ctrl + U` | 선택 영역의 주석 해제 |

```cpp
int number = 10;
std::cout << number << '\n';
```

위 두 줄을 선택한 뒤 `Ctrl+K, Ctrl+C`를 누르면 각 줄 앞에 `//`가 추가된다. 예제 코드를 잠시 실행에서 제외하고 싶을 때 유용하다.

## 서식 정리

| 단축키 | 기능 | 사용 예 |
| --- | --- | --- |
| `Ctrl + K, Ctrl + D` | 문서 전체 서식 정리 | 들여쓰기가 무너졌을 때 |
| `Ctrl + K, Ctrl + F` | 선택 영역만 서식 정리 | 수정한 함수 한 부분만 정리할 때 |

서식 정리는 들여쓰기와 공백을 프로젝트의 C++ 서식 설정에 맞춰 정리한다. 코드의 동작 자체를 바꾸지는 않는다.

## 코드 접기

| 단축키 | 기능 |
| --- | --- |
| `Ctrl + M, Ctrl + O` | 모든 정의만 남기고 코드 접기 |
| `Ctrl + M, Ctrl + M` | 현재 영역 접기 / 펼치기 |
| `Ctrl + M, Ctrl + L` | 모든 영역 펼치기 |

함수와 구조체가 많은 파일에서 필요한 함수만 빠르게 찾을 때 사용한다.

## 코드 탐색

| 단축키 | 기능 | 사용 예 |
| --- | --- | --- |
| `F12` | 정의로 이동 | 함수가 실제로 구현된 곳으로 이동 |
| `Ctrl + F12` | 선언으로 이동 | 함수 프로토타입이나 선언 위치로 이동 |
| `Shift + F12` | 모든 참조 찾기 | 어떤 변수나 함수가 어디에서 쓰였는지 확인 |
| `Ctrl + F` | 현재 파일에서 찾기 | 현재 파일의 특정 단어 찾기 |
| `Ctrl + Shift + F` | 파일 전체에서 찾기 | 프로젝트 전체에서 함수 이름 찾기 |
| `Ctrl + G` | 줄 번호로 이동 | 오류 메시지의 줄 번호로 바로 이동 |

## 코드 조각과 빠른 입력

| 단축키 | 기능 |
| --- | --- |
| `Ctrl + K, Ctrl + X` | 코드 조각(Snippet) 삽입 |
| `Ctrl + J` | 멤버 목록 / 자동 완성 목록 표시 |

예를 들어 `for`를 입력한 뒤 자동 완성 목록이나 코드 조각을 사용하면 반복문 형태를 빠르게 만들 수 있다. 다만 자동 생성된 코드는 그대로 믿지 말고, 조건식과 증감식이 의도에 맞는지 확인한다.

## 디버깅 중 자주 쓰는 단축키

| 단축키 | 기능 |
| --- | --- |
| `F5` | 디버깅 시작 또는 다음 중단점까지 계속 실행 |
| `F9` | 중단점 켜기 / 끄기 |
| `F10` | 함수 내부를 건너뛰고 다음 줄 실행 |
| `F11` | 호출한 함수 내부로 들어가기 |
| `Shift + F11` | 현재 함수에서 빠져나오기 |
| `Shift + F5` | 디버깅 중지 |

디버깅 자세한 방법은 [디버깅방법.MD](디버깅방법.MD)를 참고한다.

## 처음에는 이것부터 익히기

1. `Ctrl + K, Ctrl + C` / `Ctrl + K, Ctrl + U` — 주석 켜기와 끄기
2. `Ctrl + K, Ctrl + D` — 전체 코드 정리
3. `Ctrl + M, Ctrl + O` — 함수 목록처럼 코드 접기
4. `F12` — 함수 정의로 이동
5. `F9`, `F5`, `F10` — 가장 기본적인 디버깅
