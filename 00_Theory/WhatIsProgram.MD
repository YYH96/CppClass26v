# 프로그램과 프로세스

## 프로그램이란?

프로그램은 컴퓨터가 수행할 작업과 순서를 기록한 명령들의 묶음이다. 메모장, 게임, 계산기, 웹 브라우저처럼 설치하거나 실행하는 모든 소프트웨어가 프로그램이다.

우리가 작성하는 `.cpp` 파일은 사람이 읽기 좋은 **소스 코드**다. CPU는 C++ 문법을 직접 이해하지 못하므로, 컴파일러가 소스 코드를 CPU가 실행할 수 있는 실행 파일로 번역해야 한다.

```text
소스 코드(.cpp) ── 빌드 ──▶ 실행 파일(.exe, 프로그램)
```

`main()` 안에 작성한 코드는 프로그램이 시작했을 때 수행할 작업을 뜻한다. 예를 들어 `std::cout << "Hello World";`는 화면에 문장을 출력하라는 명령이다.

## 빌드(Build)

빌드는 소스 코드를 실행 가능한 프로그램으로 만드는 과정이다.

1. **컴파일(Compile)**: C++ 문법을 검사하고 기계어에 가까운 형태로 번역한다.
2. **링크(Link)**: 여러 코드와 라이브러리를 연결한다.
3. **실행 파일 생성**: Windows에서는 보통 `.exe` 파일이 만들어진다.

문법 오류가 있으면 컴파일 단계에서 빌드가 실패한다. 오류 메시지를 읽고 수정한 뒤 다시 빌드하는 과정도 프로그램 개발의 일부다.

## 프로세스란?

프로세스는 프로그램이 운영체제 위에서 실제로 실행되고 있는 상태다.

프로그램은 디스크에 저장되어 있는 실행 파일이고, 프로세스는 그 프로그램을 실행해 메모리에 올라온 상태다. 실행 버튼을 누르면 운영체제가 프로그램에 메모리와 CPU 실행 시간을 배정하고, CPU가 명령을 하나씩 수행한다.

```text
Calculator.exe 파일 ── 실행 ──▶ 메모리에서 동작하는 계산기 프로세스
```

같은 프로그램을 두 번 실행하면 실행 파일은 하나여도 프로세스는 두 개가 될 수 있다. 작업 관리자에 보이는 실행 중인 앱과 백그라운드 작업이 프로세스의 예다.

## 프로그램과 프로세스의 차이

| 구분 | 프로그램 | 프로세스 |
| --- | --- | --- |
| 상태 | 저장되어 있음 | 실행 중임 |
| 위치 | 디스크(SSD, HDD) | 메모리(RAM) |
| 예시 | `MyGame.exe` 파일 | 현재 실행 중인 `MyGame.exe` |
| 개수 | 실행 파일 하나 | 같은 프로그램도 여러 개 실행 가능 |

## 우리가 만들려는 것

이 수업에서는 C++로 콘솔 프로그램부터 만든다. 콘솔 프로그램은 화면에 글자를 출력하고 키보드 입력을 받아 결과를 보여 주는 프로그램이다. 화면 구성이 단순하므로 프로그램의 동작 원리에 집중하기 좋다.

커피 주문, 숫자 야구, 빙고 같은 실습도 실제 프로그램 제작 흐름을 그대로 담고 있다.

```text
문제와 규칙 정리
        ↓
알고리즘 설계
        ↓
C++ 소스 코드 작성
        ↓
빌드하여 프로그램 생성
        ↓
실행하여 프로세스로 동작 확인
```

변수, 조건문, 반복문, 배열은 모두 입력을 받고 데이터를 처리한 뒤 원하는 결과를 출력하는 프로그램을 만들기 위한 도구다.

> **소스 코드는 사람이 작성하는 명령이고, 빌드를 거치면 프로그램이 되며, 실행하면 프로세스가 된다.**
