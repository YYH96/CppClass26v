# Visual Studio 디버깅 방법

## 디버깅이란?

디버깅(Debugging)은 프로그램을 실행하다가 원하는 지점에서 잠시 멈춘 뒤, 변수 값과 함수 호출 흐름을 확인하여 문제의 원인을 찾는 과정이다.

`std::cout`으로 값을 출력하는 방법도 있지만, 디버거를 사용하면 프로그램을 멈추지 않고 코드를 수정하지 않아도 실행 중인 변수 값을 확인할 수 있다.

## 시작 전 확인할 것

수업 프로젝트는 예제 파일마다 `main()` 함수가 있다. 실행하려는 파일 하나만 빌드 대상이어야 한다.

1. Visual Studio 상단의 구성을 `Debug`, 플랫폼을 `x64`로 선택한다.
2. 솔루션 탐색기에서 실행할 `.cpp` 파일을 선택한다.
3. 다른 `main()` 파일은 **속성 → 빌드에서 제외**가 설정되어 있는지 확인한다.
4. 중단점을 설정한 뒤 디버깅을 시작한다.

`Release` 구성은 보통 최적화를 적용해 배포용 실행 파일을 만드는 구성이다. 최적화가 적용되면 변수나 코드의 실행 순서가 디버거에서 기대와 다르게 보일 수 있으므로, 처음 학습할 때는 `Debug` 구성으로 디버깅하는 것이 좋다.

## 가장 기본적인 흐름

1. 확인하고 싶은 **실행문** 왼쪽 여백을 클릭하거나 `F9`를 눌러 중단점을 만든다.
2. `F5`를 눌러 디버깅을 시작한다.
3. 프로그램은 중단점의 **해당 줄을 실행하기 직전**에 멈춘다.
4. 노란색 화살표가 현재 실행할 줄을 가리킨다.
5. 변수 위에 마우스를 올리거나 `지역 변수`, `조사식` 창에서 값을 확인한다.
6. `F10`, `F11`로 한 줄씩 진행하며 값과 흐름을 확인한다.
7. 끝내려면 `Shift + F5`를 누른다.

## 자주 쓰는 단축키

| 단축키 | 기능 | 언제 사용하는가 |
| --- | --- | --- |
| `F5` | 디버깅 시작 / 계속 | 다음 중단점까지 실행하고 싶을 때 |
| `F9` | 중단점 켜기 / 끄기 | 특정 줄에서 멈추고 싶을 때 |
| `F10` | 프로시저 단위 실행(Step Over) | 함수 내부는 건너뛰고 다음 줄로 갈 때 |
| `F11` | 한 단계씩 코드 실행(Step Into) | 호출한 함수 내부까지 들어가 확인할 때 |
| `Shift + F11` | 프로시저 나가기(Step Out) | 현재 함수의 끝까지 실행하고 호출한 곳으로 돌아갈 때 |
| `Ctrl + F10` | 커서까지 실행 | 일시적으로 커서가 있는 줄까지 빠르게 실행할 때 |
| `Shift + F5` | 디버깅 중지 | 디버그 실행을 완전히 끝낼 때 |

### `F10`과 `F11`의 차이

```cpp
int result = Add(10, 20);
```

- `F10`: `Add` 함수는 실행하지만 내부로 들어가지 않는다. 함수 호출이 끝난 다음 줄에서 멈춘다.
- `F11`: `Add` 함수의 첫 줄로 들어간다. 함수 내부의 매개변수와 지역 변수를 확인할 수 있다.

처음에는 `F11`로 함수가 호출되는 과정을 확인하고, 이미 이해한 함수는 `F10`으로 건너뛰면 된다.

## 중단점(Breakpoint)

중단점은 “이 줄을 실행하기 전에 프로그램을 멈춰 달라”는 표시다. 코드 왼쪽에 빨간 원으로 표시된다.

```cpp
int total = 0;
for (int number = 1; number <= 5; ++number)
{
    total += number; // 이 줄에 F9로 중단점을 설정한다.
}
```

반복문 안에 중단점을 걸고 `F5`를 누르면 반복할 때마다 멈춘다. `number`와 `total` 값이 어떻게 바뀌는지 확인하기 좋다.

중단점은 선언문처럼 실제 실행되지 않는 줄에는 설정할 수 없거나 동작하지 않을 수 있다. 값을 대입하는 줄, 함수 호출 줄, 조건문 내부처럼 실제로 실행되는 줄에 설정한다.

## 변수 확인하기

프로그램이 중단점에서 멈춘 상태에서만 디버그 창의 값이 의미 있다.

### 마우스로 빠르게 확인

변수 이름 위에 마우스를 올리면 현재 값이 표시된다. 가장 빠르게 값을 확인하는 방법이다.

### 지역 변수 창

`디버그 → 창 → 지역 변수` 또는 `Alt + 4`로 연다.

현재 함수 안에서 선언된 지역 변수와 매개변수를 보여 준다. 배열과 구조체는 왼쪽 화살표를 눌러 내부 요소를 펼쳐 볼 수 있다.

### 자동 변수 창

`디버그 → 창 → 자동 변수`에서 현재 줄과 주변 줄에서 사용된 변수를 볼 수 있다. 현재 실행문과 직접 관련된 값만 빠르게 보고 싶을 때 유용하다.

### 조사식(Watch) 창

계속 관찰할 변수나 식을 등록하는 창이다.

1. 멈춘 상태에서 변수 우클릭 → **조사식 추가**를 선택한다.
2. 또는 `디버그 → 창 → 조사식 → 조사식 1`을 연다.
3. 변수 이름뿐 아니라 `score + bonus`, `array[index]` 같은 식도 등록할 수 있다.

반복문을 따라가며 특정 변수 값이 계속 변하는지 확인할 때 적합하다.

## 호출 스택(Call Stack)

호출 스택은 현재 함수가 어떤 함수들을 거쳐 호출되었는지 보여 준다.

`디버그 → 창 → 호출 스택` 또는 `Ctrl + Alt + C`로 연다.

예를 들어 `main()`이 `StartGame()`을 호출하고, `StartGame()`이 `CheckAnswer()`를 호출한 상태에서 멈췄다면 호출 스택에는 대략 다음 순서가 보인다.

```text
CheckAnswer()
StartGame()
main()
```

재귀 함수에서는 같은 함수가 여러 번 쌓여 있는 모습을 확인할 수 있다. 재귀 호출이 어디까지 진행되었는지 파악할 때 특히 유용하다.

## 함수 예제로 연습하기

```cpp
int Add(int left, int right)
{
    int result = left + right;
    return result;
}

int main()
{
    int total = Add(10, 20);
    return 0;
}
```

1. `int total = Add(10, 20);` 줄에 중단점을 설정한다.
2. `F5`를 눌러 멈춘다.
3. `F11`을 눌러 `Add` 함수 안으로 들어간다.
4. 지역 변수 창에서 `left`, `right`, `result`를 확인한다.
5. `F10`으로 `result` 대입을 실행한다.
6. `Shift + F11`로 `main()`으로 돌아간다.
7. `total` 값이 30인지 확인한다.

## 자주 발생하는 문제

### 중단점이 걸리지 않는다

- 실행 중인 파일이 아닌 다른 예제 파일에 중단점을 걸었는지 확인한다.
- 현재 프로젝트의 다른 `.cpp` 파일이 빌드에서 제외되지 않아 여러 `main()`이 함께 컴파일되는지 확인한다.
- `Debug | x64` 구성과 실제 빌드한 구성이 같은지 확인한다.
- 중단점을 실제 실행되는 문장에 설정했는지 확인한다.

### 값이 생각과 다르다

추측하지 말고 값이 바뀌는 **직전 줄**에 중단점을 설정한다. `F10`으로 한 줄 실행한 뒤, 지역 변수 또는 조사식 창에서 이전 값과 다음 값을 비교한다.

### 함수 호출 흐름이 헷갈린다

`F11`로 함수 안에 들어간 다음 호출 스택을 연다. 현재 함수가 누구에게 호출되었는지 위에서 아래 방향으로 확인한다.

## 기억할 점

> 디버깅은 “코드를 한 줄씩 실행하며, 그 순간의 변수 값과 호출 흐름을 확인하는 방법”이다.

처음에는 **중단점(F9) → 시작(F5) → 한 줄 실행(F10/F11) → 변수 확인** 네 가지만 익히면 충분하다.
