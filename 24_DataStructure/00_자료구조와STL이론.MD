# 자료구조와 STL

## 자료구조란?

자료구조(Data Structure)는 데이터를 어떤 모양으로 저장하고, 어떤 방법으로 꺼내고, 추가하고, 삭제할지 정해 둔 규칙입니다.

같은 정수 100개라도 순서가 중요하면 배열이나 리스트에, 먼저 들어온 일을 먼저 처리해야 하면 큐에, 중복 없는 목록이 필요하면 셋에 저장하는 편이 알맞습니다. 자료구조 선택은 프로그램의 기능과 성능에 영향을 줍니다.

자료구조를 고르기 전에는 아래를 생각합니다.

- 순서가 필요한가?
- 중복을 허용하는가?
- 특정 위치에 빠르게 접근해야 하는가?
- 중간 삽입과 삭제가 자주 일어나는가?
- 먼저 넣은 것 또는 마지막에 넣은 것부터 꺼내야 하는가?

## STL이란?

STL(Standard Template Library)은 C++ 표준 라이브러리가 제공하는 템플릿 기반의 자료구조와 도구 모음입니다.

- 컨테이너(Container): 데이터를 저장하는 자료구조입니다. 예: vector, stack, queue, list, set
- 반복자(Iterator): 컨테이너 원소를 가리키며 순회할 때 사용하는 도구입니다.
- 알고리즘(Algorithm): 정렬, 탐색, 복사처럼 데이터를 처리하는 함수입니다. 예: std::sort, std::find
- 함수 객체(Function Object): 함수처럼 호출할 수 있는 객체입니다.

STL 컨테이너는 템플릿으로 만들어져 std::vector<int>, std::queue<std::string>처럼 저장할 자료형을 지정해 사용합니다.

## 자주 사용하는 자료구조

| 자료구조 | 핵심 구조 | 대표 STL 타입 | 주 사용 상황 |
| --- | --- | --- | --- |
| 배열(Array) | 같은 자료형을 연속된 메모리에 저장 | 기본 배열, std::array, std::vector | 인덱스로 빠르게 접근할 때 |
| 스택(Stack) | 마지막에 넣은 데이터를 먼저 꺼냄(LIFO) | std::stack | 되돌리기, 함수 호출 흐름, 괄호 검사 |
| 큐(Queue) | 먼저 넣은 데이터를 먼저 꺼냄(FIFO) | std::queue | 대기열, 작업 예약, BFS |
| 리스트(List) | 노드를 연결해 저장 | std::list | 알고 있는 위치에서 삽입·삭제가 잦을 때 |
| 트리(Tree) | 부모·자식 관계의 계층 구조 | std::set, std::map 등에 활용 | 폴더 구조, 탐색 구조 |
| 셋(Set) | 중복 없는 값을 정렬된 상태로 저장 | std::set | 중복 제거, 포함 여부 확인 |

## 1. 배열(Array)

배열은 같은 자료형의 데이터를 연속된 메모리 공간에 저장합니다. 인덱스를 사용하면 원하는 위치에 빠르게 접근할 수 있습니다.

- 장점: array[index]처럼 인덱스 접근이 빠릅니다. 시간 복잡도는 O(1)입니다.
- 단점: 기본 배열은 크기가 고정입니다. 중간에 원소를 삽입·삭제하면 뒤 원소를 옮겨야 합니다.
- std::vector는 크기를 늘릴 수 있는 가변 배열입니다. 18번 프로젝트에서 다룬 자료구조입니다.
- 24번 프로젝트에서는 STL vector 예제를 반복하지 않고, 템플릿으로 직접 만든 가변 배열을 구현합니다.

## 2. 스택(Stack)

스택은 마지막에 넣은 데이터가 가장 먼저 나오는 LIFO(Last In, First Out) 구조입니다.

push(10), push(20), push(30) 순서로 넣었다면 30, 20, 10 순서로 꺼냅니다.

- 넣기: push
- 맨 위 확인: top
- 꺼내기: pop
- 예시: 실행 취소, 웹 브라우저 뒤로 가기, 함수 호출 스택

## 3. 큐(Queue)

큐는 먼저 넣은 데이터가 가장 먼저 나오는 FIFO(First In, First Out) 구조입니다.

push(10), push(20), push(30) 순서로 넣었다면 10, 20, 30 순서로 꺼냅니다.

- 넣기: push
- 맨 앞 확인: front
- 꺼내기: pop
- 예시: 은행 대기열, 몬스터 행동 순서, 작업 예약, 너비 우선 탐색(BFS)

## 4. 리스트(List)

연결 리스트는 각 데이터가 다음 데이터의 위치를 함께 기억하는 노드(Node) 구조입니다. std::list는 양쪽 방향으로 연결된 이중 연결 리스트입니다.

- 장점: 이미 알고 있는 위치(반복자)에서는 삽입·삭제가 빠릅니다.
- 단점: 배열처럼 list[3]으로 바로 접근할 수 없습니다. 원하는 위치까지 앞에서부터 이동해야 합니다.
- 주의: 단순 순회나 끝에 추가하는 목적이라면 캐시 효율 때문에 vector가 더 적합한 경우도 많습니다.

## 5. 트리(Tree)

트리는 부모 노드와 자식 노드로 이루어진 계층형 자료구조입니다.

- 가장 위의 노드: 루트(Root)
- 아래로 연결된 노드: 자식(Child)
- 같은 부모를 가진 노드: 형제(Sibling)
- 예시: 폴더 구조, 조직도, 게임 오브젝트 계층

이진 탐색 트리(Binary Search Tree)는 왼쪽에는 작은 값, 오른쪽에는 큰 값을 두어 탐색하기 쉽게 만든 트리입니다. std::set과 std::map은 보통 균형 잡힌 탐색 트리 방식으로 구현되지만, 표준은 내부 구현 방식을 강제하지 않습니다.

## 6. 셋(Set)

셋은 중복을 허용하지 않는 자료구조입니다. std::set은 값을 정렬된 상태로 관리합니다.

- 같은 값을 여러 번 넣어도 한 개만 보관합니다.
- 삽입, 삭제, 탐색은 일반적으로 O(log N)입니다.
- 예시: 이미 방문한 좌표, 중복 없는 아이템 ID, 허용된 명령어 목록

std::unordered_set도 중복을 허용하지 않지만 해시를 사용하며 정렬 순서를 보장하지 않습니다. 이 프로젝트에서는 먼저 정렬되는 std::set부터 다룹니다.

## 선택 요약

- 번호로 바로 접근해야 한다 → 배열 또는 vector
- 마지막 작업부터 되돌린다 → stack
- 들어온 순서대로 처리한다 → queue
- 특정 위치의 삽입·삭제가 핵심이다 → list
- 부모·자식 계층을 표현한다 → tree
- 중복을 제거하고 정렬된 값을 관리한다 → set

자료구조에는 절대적으로 가장 좋은 선택이 없습니다. 프로그램이 자주 하는 작업에 맞는 자료구조를 고르는 것이 중요합니다.
