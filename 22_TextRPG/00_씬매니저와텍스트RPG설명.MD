# 씬 매니저를 이용한 TextRPG

씬(Scene)은 게임에서 하나의 독립된 화면과 그 화면의 동작을 뜻합니다. 예를 들면 로비, 인게임, 전투, 상점 화면이 각각 하나의 씬이 될 수 있습니다.

이 프로젝트에서는 로비와 인게임을 분리합니다.

```text
게임 매니저
 ├─ 플레이어 데이터
 └─ 씬 매니저
     ├─ 로비 씬
     ├─ 인게임 씬
     └─ 전투 씬 ← 현재 씬
```

## 역할

- `CGameManager`: 게임 전체 실행, 플레이어 데이터 생성·해제를 담당한다.
- `CSceneManager`: 만들어 둔 씬을 보관하고 현재 씬의 `Draw`, `Update`를 호출한다. `ChangeScene`으로 화면을 전환한다.
- `CBaseScene`: 모든 씬이 공통으로 가지는 `Enter`, `Exit`, `Draw`, `Update` 인터페이스다.
- `CLobbyScene`: 이름과 직업을 입력받고 플레이어를 만든 뒤 인게임 씬으로 전환한다.
- `CGameScene`: 플레이어 정보를 보여 주고 탐색·휴식·로비 복귀를 처리한다.
- `CCombatScene`: 몬스터와 공격·방어·도망을 처리하고, 전투 결과에 따라 인게임 씬으로 돌아간다.
- `SaveSystem`: 내 문서의 `TextRPGSave.txt`에 플레이어·층 진행도를 저장하고 불러온다.

## 로비에서 인게임으로 전환되는 순서

1. 게임 매니저가 씬 매니저를 만들고 로비 씬을 현재 씬으로 지정한다.
2. 로비 씬이 이름과 직업을 입력받아 플레이어를 생성한다.
3. 로비 씬이 `ChangeScene(eSceneType::GAME)`을 호출한다.
4. 씬 매니저는 기존 로비 씬의 `Exit()`을 호출하고, 인게임 씬의 `Enter()`을 호출한다.
5. 다음 게임 루프부터 인게임 씬의 `Draw()`와 `Update()`가 실행된다.

전투·상점 씬을 추가하고 싶다면 `eSceneType`에 새 값을 넣고, `CBaseScene`을 상속한 새 클래스를 만든 뒤 `CSceneManager::Init()`에 등록하면 됩니다.

## 전투 씬 전환

인게임에서 탐색 결과가 몬스터 조우라면 `CGameManager`가 `CMonster`를 생성하고 `ChangeScene(eSceneType::COMBAT)`을 호출합니다. 전투 씬에서는 공격·방어·도망을 처리합니다.

- 공격으로 몬스터 HP가 0 이하가 되면 골드와 경험치를 지급하고 인게임 씬으로 돌아간다.
- 방어는 몬스터의 이번 공격 피해를 절반으로 줄인다.
- 도망은 몬스터를 삭제하고 인게임 씬으로 돌아간다.
- 플레이어 HP가 0 이하가 되면 씬 매니저에 게임 종료를 요청한다.
- `CMonster`는 `void (*)()` 형태의 함수 포인터에 종족별 콘솔 그림 함수를 저장하고, 전투 화면에서 호출한다.

## 탐색 이벤트와 층 보상

`GameInfo.h`의 `enum class eEventType`은 탐색 결과를 `NONE`, `GOLD`, `BATTLE`, `NEXT_STAGE`로 표현합니다. 숫자 `0`, `1`, `2`를 직접 비교하지 않고 `switch`로 처리합니다.

- 시작 층은 1층이고, 최대 골드 획득량은 100G다.
- `GOLD` 이벤트는 1G부터 현재 최대 골드까지 무작위 보상을 준다.
- `NEXT_STAGE` 이벤트가 발생하면 층이 하나 올라간다.
- 층이 올라갈 때 최대 골드 획득량은 1.5배가 된다. 예: `100 → 150 → 225 → 337`
