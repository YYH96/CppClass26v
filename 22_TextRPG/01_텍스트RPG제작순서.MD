# TextRPG 제작 순서

처음부터 전투·몬스터·파일 저장을 한 번에 만들기보다, **실행되는 가장 작은 게임**을 먼저 만든 뒤 기능을 하나씩 추가합니다.

```text
1. 게임 루프
   ↓
2. 플레이어 데이터
   ↓
3. 로비 씬
   ↓
4. 씬 매니저와 인게임 씬 전환
   ↓
5. 탐색 이벤트
   ↓
6. 몬스터와 전투 씬
   ↓
7. 층·보상·저장 기능 확장
```

## 1. 게임 루프 만들기

`main()`에서 `CGameManager::GameRun()`을 호출합니다. 게임 매니저는 다음 순서로 계속 실행합니다.

```cpp
while (sceneManager->IsRunning())
{
    화면을 지운다;
    현재 씬을 그린다;
    현재 씬의 입력과 로직을 처리한다;
}
```

이 단계의 목표는 화면에 글자 하나를 출력하고, 종료 메뉴를 통해 반복문을 끝내는 것입니다.

## 2. 플레이어 데이터 만들기

`CPlayer`에 이름, 직업, HP, 공격력, 골드, 레벨, 경험치를 넣습니다.

- `Initialize`: 로비에서 입력한 이름·직업으로 시작 능력치를 설정한다.
- `PrintInfo`: 현재 플레이어 상태를 출력한다.
- `Rest`, `AddGold`, `AddExp`, `TakeDamage`: 게임 중 바뀌는 상태를 한곳에서 처리한다.

**확인:** 임시 플레이어를 만든 뒤 능력치를 출력할 수 있는가?

## 3. 로비 씬 만들기

`CLobbyScene`은 게임 시작 화면입니다.

1. 게임 제목을 출력한다.
2. 이름과 직업을 입력받는다.
3. `CGameManager::CreatePlayer()`로 플레이어를 만든다.

아직은 로비에서 입력받기만 해도 충분합니다.

## 4. 씬 매니저와 인게임 씬 연결하기

`CBaseScene`을 만들고, 모든 씬이 `Draw`, `Update`를 구현하게 합니다.  
`CSceneManager`는 씬을 보관하고 현재 씬 하나만 실행합니다.

```cpp
gameManager->GetSceneManager()->ChangeScene(eSceneType::GAME);
```

로비에서 캐릭터 생성이 끝나면 위 코드로 인게임 씬으로 넘어갑니다.

**확인:** 로비 입력 뒤 인게임 메뉴가 표시되는가?

## 5. 탐색 이벤트 추가하기

탐색 메뉴를 선택하면 `eEventType` 중 하나를 무작위로 뽑습니다.

- `NONE`: 아무 일도 일어나지 않는다.
- `GOLD`: 현재 층의 최대 골드 범위에서 보상을 얻는다.
- `BATTLE`: 몬스터를 만들고 전투 씬으로 이동한다.
- `NEXT_STAGE`: 다음 층으로 올라가며 최대 골드가 1.5배 증가한다.

이벤트는 숫자 `0`, `1`, `2`가 아닌 `enum class`와 `switch`로 처리합니다.

## 6. 몬스터와 전투 씬 만들기

`CMonster`에는 이름, HP, 공격력, 골드 보상, 경험치 보상을 둡니다. 슬라임·고블린·오크 중 하나를 생성하고, 함수 포인터로 종족별 콘솔 그림을 출력합니다.

전투 씬의 흐름은 다음과 같습니다.

```text
공격 선택 → 몬스터 피해 처리 → 생존 시 몬스터 반격
           └→ 몬스터 처치 시 보상 지급 → 인게임 씬 복귀

방어 선택 → 몬스터 공격 피해 절반 처리
도망 선택 → 몬스터 삭제 → 인게임 씬 복귀
```

**확인:** 탐색 → 전투 → 승리 또는 도망 → 인게임 복귀가 되는가?

## 7. 다음 확장 순서

현재 구조가 안정되면 아래 순서로 확장합니다.

1. 몬스터 종류별 특별 공격과 방어력
2. 상점 씬 (`eSceneType::SHOP` 추가)
3. 인벤토리와 아이템 클래스
4. 파일 입출력으로 플레이어 저장·불러오기
5. 전투·상점·게임오버 씬을 추가한 씬 전환 다이어그램 갱신

새 화면을 만들 때는 `CBaseScene` 상속 클래스 생성 → `eSceneType` 추가 → `CSceneManager::Init()` 등록 → 전환 호출 순서로 작업합니다.
