# TextRPG 세이브와 로드

저장 파일은 내 문서 폴더에 아래 이름으로 만들어집니다.

```text
내 문서\TextRPGSave.txt
```

SaveSystem::GetSaveFilePath()은 Windows API인 SHGetKnownFolderPath(FOLDERID_Documents)로 실제 내 문서 경로를 가져옵니다. 사용자가 문서 폴더 위치를 옮긴 경우에도 반영됩니다. 문서 경로를 가져오지 못한 특수 환경에서만 현재 작업 폴더에 저장합니다.

## 로비 메뉴

```text
[1] 새 게임
[2] 이어하기
```

- 새 게임: 이름·직업을 입력받아 새 플레이어를 만든다.
- 이어하기: 텍스트 파일에서 플레이어 능력치, 보유 골드, 레벨, 현재 층, 최대 골드 획득량을 읽는다.
- 저장 파일이 없거나 내용이 비어 있거나 형식이 잘못됐다면 이어하기를 선택해도 새 게임으로 진행한다.

## 저장 시점

탐색, 휴식, 전투 결과에서는 자동 저장하지 않습니다. 인게임 씬에서 [4] 저장하기를 선택했을 때만 현재 진행도를 저장합니다. 몬스터 자체는 저장하지 않으므로, 저장 후 다시 이어하기를 하면 인게임 씬에서 시작합니다.

## 텍스트 파일 형식

아래 순서로 한 줄씩 저장합니다.

```text
이름
직업 번호
현재 HP
최대 HP
공격력
골드
레벨
경험치
현재 층
현재 층의 최대 골드
```

저장 순서와 불러오기 순서가 다르면 데이터가 잘못 해석됩니다. 파일에 `std::string`이 포함되어 있으므로 구조체 전체를 바이너리로 저장하지 않고, 각 데이터를 텍스트로 나누어 저장합니다.
