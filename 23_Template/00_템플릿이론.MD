# 템플릿(Template)

## 템플릿이란?

템플릿은 **자료형만 다른 같은 로직을 하나의 코드로 작성**하기 위한 C++ 문법입니다. 이를 일반화 프로그래밍(Generic Programming)이라고 합니다.

```cpp
int Add(int left, int right);
float Add(float left, float right);
double Add(double left, double right);
```

위 함수들은 자료형만 다르고 덧셈이라는 로직은 같습니다. 자료형마다 오버로딩을 계속 만들면 코드가 중복되고, 로직을 수정할 때마다 모든 함수를 수정해야 합니다.

## 데이터 타입의 추상화

`template<typename T>`에서 `T`는 아직 정해지지 않은 **자료형 자리**입니다. 호출할 때 `int`, `double`, `std::string`처럼 실제 자료형이 결정됩니다.

```cpp
template<typename T>
T Add(T left, T right)
{
    return left + right;
}
```

## 컴파일러와 템플릿 인스턴스

템플릿은 호출 자체가 함수나 클래스 하나를 즉시 만드는 것이 아니라 **설계도**에 가깝습니다. 컴파일러는 실제로 사용된 자료형에 맞는 코드를 컴파일 시간에 생성합니다. 이렇게 생성된 결과를 템플릿 인스턴스라고 합니다.

```cpp
Add(1, 2);        // Add<int>(int, int) 형태의 코드가 생성된다.
Add(1.5, 2.5);    // Add<double>(double, double) 형태의 코드가 생성된다.
```

## 템플릿의 종류

- **함수 템플릿**: 로직은 같고 매개변수·반환형만 달라질 때 사용합니다.
- **클래스 템플릿**: Box, Stack, Vector처럼 구조는 같고 저장할 자료형만 달라질 때 사용합니다.

## 알아둘 점

- 컴파일러가 템플릿 코드를 생성하려면 **정의 전체를 호출하는 cpp 파일에서 볼 수 있어야** 합니다. 그래서 템플릿 구현은 보통 헤더 파일에 작성합니다.
- 템플릿 안에서 사용하는 연산자나 함수는 실제 자료형도 지원해야 합니다. 예를 들어 `left + right`를 사용한다면 `T`에 덧셈 연산이 가능해야 합니다.
- 서로 다른 자료형을 함께 전달하면 자료형 추론에 실패할 수 있습니다. 이때는 `Add<double>(10, 3.5)`처럼 원하는 자료형을 직접 지정할 수 있습니다.
- 템플릿 인자는 하나로 제한되지 않습니다. `template<typename T, typename U>`처럼 여러 자료형 자리를 선언할 수 있으며, `int`와 `double`처럼 서로 다른 자료형을 함께 받을 때 사용합니다.
