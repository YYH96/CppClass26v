# 참조(Reference)

## 참조란?

참조(reference)는 이미 존재하는 변수에 붙이는 **또 다른 이름(별칭)** 입니다.

```cpp
int hp = 100;
int& hpReference = hp;

hpReference = 50; // hp 자체가 50으로 바뀝니다.
```

`hp`와 `hpReference`는 서로 다른 int 두 개가 아닙니다. 같은 변수 하나를 다른 이름으로 부르는 것입니다.

```text
hp ───────────┐
              ├─ 같은 int 변수 하나
hpReference ──┘
```

## 일반 참조(`&`)의 특징

- 선언과 동시에 반드시 기존 변수에 연결해야 합니다.
- 한 번 연결하면 다른 변수를 참조하도록 바꿀 수 없습니다.
- 참조를 통해 값을 바꾸면 원본 값도 바뀝니다.
- 일반 참조는 수정 가능한 lvalue 변수에 연결할 수 있습니다.

```cpp
int hp = 100;
int& reference = hp; // 가능

// int& emptyReference; // 오류: 선언과 동시에 연결해야 합니다.
// int& literalReference = 10; // 오류: 일반 참조는 임시 rvalue에 연결할 수 없습니다.
```

`sizeof(reference)`는 참조가 가리키는 원본의 크기로 계산됩니다. 참조가 내부적으로 별도 공간을 사용하는지는 컴파일러 구현에 따른 사항이며, `sizeof`만으로 참조 자체의 크기를 알 수는 없습니다.

## 포인터와 참조 비교

| 항목 | 포인터 | 참조 |
| --- | --- | --- |
| 의미 | 주소를 저장하는 변수 | 기존 변수의 별칭 |
| 선언 | `int* pointer` | `int& reference` |
| 대상 변경 | 다른 주소를 저장할 수 있음 | 처음 연결한 대상을 바꿀 수 없음 |
| null 상태 | `nullptr` 가능 | null 상태를 정상적으로 표현하지 않음 |
| 값 접근 | `*pointer` | 변수처럼 `reference` |
| 주 사용처 | 주소 없음 표현, 동적 할당, 배열 순회 | 반드시 존재하는 원본을 함수에서 다룰 때 |

참조는 내부적으로 포인터와 비슷하게 구현될 수 있지만, C++ 코드에서는 별칭이라는 규칙으로 사용합니다.

## 함수 매개변수에서의 참조

### 값 전달

함수에 복사본을 전달합니다. 함수 안에서 바꿔도 원본은 변하지 않습니다.

```cpp
void Add100(int value)
{
    value += 100; // 복사본만 변경
}
```

### 참조 전달

원본에 별칭을 붙여 전달합니다. 함수 안에서 바꾸면 원본이 바뀝니다.

```cpp
void Add100(int& value)
{
    value += 100; // 원본 변경
}
```

### const 참조 전달

원본을 복사하지 않고 읽기만 할 때 사용합니다. 큰 클래스 객체·문자열을 함수에 전달할 때 자주 사용합니다.

```cpp
void PrintPlayer(const Player& player);
```

함수 안에서 `player`를 바꾸려 하면 컴파일 오류가 나므로, 읽기 전용이라는 의도도 드러납니다.

## 포인터의 참조

`int*&`는 “int 포인터 변수 자체의 참조”입니다.

```cpp
int* pointer = nullptr;
int*& pointerReference = pointer;
```

함수에서 `Type*&`를 받으면 호출한 쪽의 포인터 변수에 새 주소를 넣거나 `nullptr`로 바꿀 수 있습니다. 동적 객체를 만들어 호출자에게 전달하는 예시에 사용합니다.

## rvalue 참조(`&&`)와 만능 참조

`Type&&`는 임시 값(rvalue)을 받을 수 있는 rvalue 참조입니다. 이동 생성자·이동 대입 연산자에서 자원 소유권을 효율적으로 넘길 때 사용합니다. 자세한 원리는 `15_Constructor`의 lvalue/rvalue와 이동 생성자를 함께 봅니다.

함수 템플릿에서 타입 추론을 받는 `T&&`는 lvalue와 rvalue를 모두 받을 수 있으며 이를 **만능 참조(universal reference)** 또는 **전달 참조(forwarding reference)** 라고 합니다. 이때 `std::forward`를 사용하면 받은 값의 lvalue/rvalue 성질을 다음 함수로 전달할 수 있습니다.

```cpp
template <typename T>
void Forward(T&& value)
{
    Use(std::forward<T>(value));
}
```

이 부분은 템플릿 학습 뒤에 다시 다룹니다.
