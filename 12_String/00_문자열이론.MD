# 문자열 (String)

문자열은 여러 문자를 순서대로 표현한 데이터입니다. C++에서는 크게 C 스타일 문자열과 `std::string`을 만날 수 있습니다.

## C 스타일 문자열

C 스타일 문자열은 `char` 배열이며, 문자열의 끝을 `\0`(널 문자)로 표시합니다.

```cpp
char message[6] = "Hello";
// H, e, l, l, o, \0 : 총 6칸 필요
```

널 문자가 없으면 출력 함수가 어디까지 문자열인지 알 수 없어 배열 밖의 메모리까지 읽을 수 있습니다. 배열 크기와 널 문자를 직접 관리해야 하므로 주의가 필요합니다.

### char 배열과 char 포인터

```cpp
char name[] = "Kim";          // 수정 가능한 문자 배열
char* pName = name;            // 위 배열을 가리키는 포인터
const char* job = "Warrior";  // 문자열 리터럴을 읽기 전용으로 가리키는 포인터
```

- `char name[]`: 문자와 널 문자를 저장할 실제 배열 공간을 만듭니다. `name[0] = 'T';`처럼 내용을 수정할 수 있습니다.
- `char* pName`: 수정 가능한 `char` 배열의 주소를 저장할 때 사용할 수 있습니다.
- `const char* job`: 문자열 리터럴을 가리킬 때 사용합니다. 포인터가 다른 문자열을 가리키게 바꿀 수는 있지만, 리터럴 내부 문자를 수정하면 안 됩니다.

```cpp
// char* wrong = "Kim"; // C++에서는 문자열 리터럴을 수정 가능한 char*로 받을 수 없음
```

## std::string

`std::string`은 C++ 표준 라이브러리가 제공하는 문자열 클래스입니다. `<string>` 헤더를 포함해 사용합니다.

```cpp
#include <string>

std::string playerName = "Alice";
playerName += "님";
```

문자열 길이에 맞춰 공간을 관리하고, `+`, `+=`, `find`, `substr`처럼 사용하기 편리한 기능을 제공합니다. 새로운 C++ 코드에서는 보통 `std::string`을 우선 사용합니다.

## 자주 쓰는 std::string 기능

| 코드 | 의미 |
| --- | --- |
| `text.size()` 또는 `text.length()` | 문자열 길이 반환 |
| `text.empty()` | 빈 문자열인지 확인 |
| `text[i]` | i번째 문자 접근 (인덱스는 0부터 시작) |
| `text += other` | 문자열 뒤에 붙이기 |
| `text.append(other)` | 문자열 뒤에 붙이기 |
| `text.insert(index, value)` | 지정 위치에 삽입 |
| `text.erase(index, count)` | 일부 문자 제거 |
| `text.replace(index, count, value)` | 일부 문자를 다른 문자열로 교체 |
| `text.substr(index, count)` | 일부 문자열을 잘라 새 문자열로 반환 |
| `text.find(word)` | 처음 찾은 위치 반환 |

`find`가 문자열을 찾지 못하면 `std::string::npos`를 반환합니다.

```cpp
std::size_t position = text.find("cat");
if (position == std::string::npos)
{
    // 찾지 못함
}
```

## 입력: cin과 getline

```cpp
std::cin >> word;             // 공백 전까지만 입력
std::getline(std::cin, line); // 공백을 포함한 한 줄 전체 입력
```

`cin`으로 숫자나 단어를 입력한 뒤 곧바로 `getline`을 사용하면, 입력 버퍼에 남은 줄바꿈 때문에 빈 문자열을 받을 수 있습니다. 이때는 다음처럼 앞의 공백을 처리한 뒤 한 줄을 읽을 수 있습니다.

```cpp
std::getline(std::cin >> std::ws, line);
```

> !기억 - `std::string`의 인덱스는 0부터 시작하며, 유효 범위 밖 인덱스에 접근하면 안 됩니다.
