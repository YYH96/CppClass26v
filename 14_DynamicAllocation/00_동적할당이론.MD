# 동적 할당(Dynamic Allocation)

## 동적 할당이란?

동적 할당은 프로그램이 실행되는 **런타임(runtime)** 에 필요한 크기의 메모리를 힙(Heap) 영역에 확보하고, 사용이 끝나면 직접 돌려주는 방법입니다.

```text
스택(Stack) : 함수 안의 지역 변수처럼 범위가 끝나면 자동으로 정리되는 메모리
힙(Heap)    : new 등으로 직접 확보하고, delete 등으로 직접 해제해야 하는 메모리
```

```cpp
int number = 10;          // 지역 변수: 함수가 끝나면 자동 정리
int* dynamicNumber = new int(10); // 힙에 int 하나를 동적으로 확보
delete dynamicNumber;     // 사용자가 직접 해제
```

## 왜 사용할까?

- 실행하기 전에는 크기를 알 수 없는 배열을 만들 수 있습니다.
- 필요할 때만 메모리를 확보하고, 사용이 끝나면 돌려줄 수 있습니다.
- 연결 리스트, 트리, 그래프처럼 실행 중 구조가 변하는 자료 구조를 구현할 수 있습니다.
- 객체를 필요한 시점에 만들고, 수명이 끝나는 시점을 직접 관리할 수 있습니다.

다만 동적 할당은 “큰 배열을 만들기 위한 기본 선택”이 아닙니다. 크기가 컴파일 시점에 정해진 작은 데이터는 일반 지역 변수나 배열이 더 단순하고 안전합니다.

## C++의 `new`와 `delete`

### 값 하나 할당하기

```cpp
int* number = new int(100); // 힙에 int 하나를 만들고 100으로 초기화

std::cout << *number << '\n';

delete number;  // int 하나를 해제
number = nullptr; // 해제 후 남은 주소를 지워 둡니다.
```

`new`는 메모리를 확보한 뒤 객체의 **생성자**를 호출합니다. `delete`는 객체의 **소멸자**를 호출한 뒤 메모리를 반환합니다. 그래서 C++ 객체에는 `malloc/free`보다 `new/delete` 조합이 맞습니다.

## 동적 배열: `new[]`와 `delete[]`

```cpp
int count = 5;
int* scores = new int[count]{}; // int 5개를 0으로 초기화

scores[0] = 100;

delete[] scores; // 배열은 반드시 delete[]로 해제
scores = nullptr;
```

| 할당 | 해제 |
| --- | --- |
| `new Type` | `delete pointer` |
| `new Type[count]` | `delete[] pointer` |

`new[]`로 만든 배열을 `delete`로 해제하거나, `new`로 만든 하나의 값을 `delete[]`로 해제하면 **정의되지 않은 동작**입니다. 객체 배열에서는 소멸자를 몇 번 호출해야 하는지 달라지므로 특히 위험합니다.

## 반드시 조심할 문제

### 메모리 누수(Memory Leak)

`new`로 확보한 뒤 `delete`하지 않으면 해당 메모리를 잃어버립니다. 프로그램이 계속 실행되는 게임·서버에서는 누수가 쌓여 메모리 부족으로 이어질 수 있습니다.

```cpp
int* number = new int(10);
// delete number;를 빼먹으면 메모리 누수
```

### 댕글링 포인터(Dangling Pointer)

메모리를 해제했는데 포인터 변수에는 이전 주소가 남아 있는 상태입니다. 해제된 메모리를 다시 읽거나 쓰면 안 됩니다.

```cpp
delete number;
number = nullptr; // 이후 실수로 *number를 사용하기 어렵게 만듭니다.
```

### 이중 해제(Double Free)

같은 메모리를 두 번 `delete`하면 안 됩니다. 첫 번째 `delete` 후 포인터를 `nullptr`로 바꾸면, 두 번째 `delete nullptr;`는 안전하게 아무 작업도 하지 않아 실수를 줄일 수 있습니다.

## C 방식 `malloc/calloc/realloc/free`와 비교

노션의 C 방식 함수도 알아둘 필요가 있습니다. C 라이브러리 함수는 `<cstdlib>`에서 사용합니다.

| 함수 | 역할 | 초기화 |
| --- | --- | --- |
| `malloc(바이트 수)` | 지정 바이트만큼 확보 | 초기화하지 않음 |
| `calloc(개수, 요소 크기)` | 개수 × 크기만큼 확보 | 모든 비트를 0으로 설정 |
| `realloc(기존 주소, 새 바이트 수)` | 블록 크기 변경 | 새 위치로 옮겨질 수 있음 |
| `free(주소)` | C 방식 메모리 해제 | - |

`malloc/calloc/realloc`은 생성자를 호출하지 않고, `free`는 소멸자를 호출하지 않습니다. 따라서 클래스 객체처럼 생성·소멸 규칙이 있는 C++ 객체에는 적합하지 않습니다.

> **절대 섞지 않습니다.** `new`로 할당한 메모리는 `delete` 또는 `delete[]`로, `malloc/calloc/realloc`으로 할당한 메모리는 `free`로 해제합니다.

## 현대 C++에서는?

이 단원에서는 메모리의 원리를 배우기 위해 원시 포인터와 `new/delete`를 직접 사용합니다. 실제 C++ 코드에서는 소유권을 자동으로 관리하는 `std::vector`, `std::string`, `std::unique_ptr` 등을 우선 사용합니다. 이 도구들은 나중에 STL·스마트 포인터 단원에서 다룹니다.
