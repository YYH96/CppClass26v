# 클래스(Class)

## 클래스란?

클래스는 **멤버 변수(데이터)** 와 **멤버 함수(기능)** 를 한 곳에 묶어 정의하는 사용자 정의 자료형입니다.

게임의 플레이어를 예로 들면, 이름·체력·레벨 같은 데이터와 공격·회복·정보 출력 같은 기능은 서로 관련이 있습니다. 클래스를 사용하면 이렇게 관련된 데이터와 기능을 `Player`라는 하나의 자료형으로 표현할 수 있습니다.

```cpp
class Player
{
private:
    int mHp;            // 멤버 변수: 플레이어의 데이터

public:
    void TakeDamage(int damage); // 멤버 함수: 플레이어의 기능
};
```

`Player player;`처럼 클래스로 실제 값을 만들면 이를 **객체(object)** 라고 합니다. 즉, 클래스는 설계도이고 객체는 설계도로 만든 실제 대상입니다.

## 구조체와 클래스

`struct`와 `class` 모두 멤버 변수와 멤버 함수를 가질 수 있습니다. 가장 먼저 기억할 차이는 **기본 접근 지정자**입니다.

| 선언 | 기본 접근 지정자 |
| --- | --- |
| `struct` | `public` |
| `class` | `private` |

```cpp
struct Position
{
    int x; // 기본이 public
};

class Player
{
    int hp; // 기본이 private
};
```

## 접근 지정자와 캡슐화

클래스는 데이터를 아무 곳에서나 바꾸지 못하게 막고, 필요한 기능만 공개할 수 있습니다. 이를 **캡슐화**라고 합니다.

- `public`: 객체를 사용하는 외부 코드에서도 접근할 수 있습니다. 사용 방법(인터페이스)을 둡니다.
- `private`: 해당 클래스 내부에서만 접근할 수 있습니다. 보호할 데이터에 사용합니다.
- `protected`: 상속받은 클래스에서는 접근할 수 있지만 외부에서는 접근할 수 없습니다. 상속에서 자세히 다룹니다.

예를 들어 체력은 음수가 되면 안 됩니다. `hp`를 `private`으로 감추고 `TakeDamage()`를 통해서만 바꾸면, 함수 안에서 0 아래로 내려가지 않도록 검증할 수 있습니다.

## 생성자와 소멸자

생성자와 소멸자는 객체의 생성·소멸 시점에 자동으로 호출되는 특별한 멤버 함수입니다.

- **생성자**: 클래스 이름과 같고 반환형이 없습니다. 객체가 만들어질 때 초기 상태를 준비합니다.
- **소멸자**: `~클래스이름()` 형태이며 반환형과 매개변수가 없습니다. 객체가 사라질 때 자동 호출됩니다.
- 생성자·소멸자는 일반 함수처럼 `객체.생성자()`로 직접 호출하지 않습니다.

멤버 변수는 가능하면 생성자 본문의 대입보다 **멤버 초기화 목록**으로 초기화합니다.

```cpp
Player(const std::string& name, int hp)
    : mName(name), mHp(hp)
{
}
```

## `this`와 `const` 멤버 함수

멤버 함수 안에서는 현재 객체를 가리키는 `this` 포인터를 사용할 수 있습니다. 매개변수 이름과 멤버 변수 이름이 같을 때 구분하는 용도로도 쓰입니다.

```cpp
void SetName(const std::string& name)
{
    this->mName = name;
}
```

객체의 상태를 바꾸지 않는 조회 함수 뒤에는 `const`를 붙입니다. 그러면 함수 내부에서 멤버 값을 바꾸려 하면 컴파일 오류가 나므로, 읽기 전용 기능임을 코드로 표시할 수 있습니다.

```cpp
int GetHp() const;
```

## static 멤버

일반 멤버 변수는 객체마다 하나씩 존재합니다. 반면 `static` 멤버 변수는 **클래스 전체가 하나만 공유**합니다. 생성한 몬스터 수처럼 모든 객체가 함께 봐야 하는 값에 활용할 수 있습니다.

`static` 멤버 함수는 특정 객체의 멤버 변수에는 접근할 수 없고, static 멤버만 직접 다룰 수 있습니다. 객체 없이 `Monster::GetCreatedCount()`처럼 클래스 이름으로 호출할 수 있습니다.

> 상속, 가상 함수, 다형성은 클래스 Part.2에서 이어서 다룹니다.
