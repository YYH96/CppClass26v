# vector와 가변 배열

## vector란?

`std::vector`는 **같은 자료형의 데이터를 순서대로 저장하는 가변 배열**입니다.
일반 배열은 `int numbers[10];`처럼 처음에 크기를 정하면 나중에 크기를 바꾸기 어렵습니다. 반면 vector는 실행 중에도 원소를 뒤에 추가하거나 제거할 수 있습니다.

```cpp
#include <vector>

std::vector<int> scores;          // 처음에는 비어 있는 int 가변 배열
std::vector<int> levels = { 1, 2, 3 };
```

vector도 배열처럼 원소가 **연속된 메모리 공간**에 저장됩니다. 그래서 `values[0]`, `values[1]`처럼 인덱스로 빠르게 접근할 수 있습니다.

## 자료구조란?

자료구조(Data Structure)는 데이터를 **어떤 모양으로 저장하고, 어떻게 꺼내 쓸지 정하는 방법**입니다.

- 배열 / vector: 순서가 있는 여러 값을 저장한다.
- 스택: 마지막에 넣은 값을 먼저 꺼낸다.
- 큐: 먼저 넣은 값을 먼저 꺼낸다.
- 맵: 이름(키)을 이용해 값을 찾는다.

지금은 그중에서 가장 자주 처음 만나는 가변 배열인 vector를 사용합니다.

## STL이란?

STL(Standard Template Library)은 C++ 표준 라이브러리에 들어 있는, 자주 사용하는 자료구조와 기능 모음입니다.

- 컨테이너(Container): 데이터를 담는 도구. `vector`, `string`, `map` 등
- 반복자(Iterator): 컨테이너의 원소를 가리키며 순회하는 도구
- 알고리즘(Algorithm): 정렬, 찾기 등 자주 쓰는 기능

`std::vector`는 STL의 컨테이너입니다. `#include <vector>`를 작성하고 `std::vector<자료형>` 형태로 사용합니다.

## 자주 쓰는 함수

| 코드 | 의미 |
| --- | --- |
| `push_back(value)` | 맨 뒤에 원소를 추가한다. |
| `emplace_back(...)` | 맨 뒤에서 객체를 바로 생성한다. |
| `pop_back()` | 맨 뒤 원소 하나를 제거한다. 비어 있을 때 호출하면 안 된다. |
| `size()` | 현재 원소 개수를 반환한다. |
| `empty()` | 비어 있으면 `true`를 반환한다. |
| `front()`, `back()` | 첫 번째, 마지막 원소를 반환한다. 비어 있을 때 호출하면 안 된다. |
| `[]` | 인덱스로 원소에 접근한다. 범위를 검사하지 않는다. |
| `at(index)` | 인덱스로 원소에 접근한다. 범위를 벗어나면 예외를 발생시킨다. |
| `insert(위치, 값)` | 지정한 위치 앞에 원소를 삽입한다. |
| `erase(위치)` | 지정한 위치의 원소를 제거한다. |
| `clear()` | 모든 원소를 제거한다. |
| `reserve(개수)` | 미리 필요한 메모리 공간을 확보한다. 원소 개수는 변하지 않는다. |

## 주의할 점

vector의 크기가 커져 새 메모리 공간으로 옮겨질 수 있습니다. 이때 vector 원소를 가리키던 포인터, 참조, 반복자는 더 이상 유효하지 않을 수 있습니다. 처음에는 **vector에 원소를 추가한 뒤에는 기존 원소의 주소를 계속 믿지 않는다** 정도로 기억하면 충분합니다.
