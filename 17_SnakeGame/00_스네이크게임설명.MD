# 콘솔 스네이크 게임

## 게임 규칙과 조작

- `W`, `A`, `S`, `D`: 뱀의 이동 방향을 바꿉니다.
- `F`: 먹이입니다. 먹으면 점수가 10점 오르고 꼬리가 한 칸 늘어납니다.
- 벽 또는 자기 꼬리에 부딪히면 게임이 끝납니다.
- `X`: 게임을 종료합니다.

## 코드의 구성

이 게임은 지금까지 배운 구조체, 배열, 열거형, 함수, 반복문을 하나의 실습에 연결한 예제입니다.

```text
Setup() : 게임 시작 상태를 준비
Draw()  : 현재 게임 화면을 출력
Input() : 키보드 입력을 받아 방향 변경
Logic() : 머리·꼬리 이동, 충돌, 먹이 처리
```

`main()`의 반복문은 게임이 끝날 때까지 `Draw → Input → Logic` 순서를 반복합니다.

```cpp
while (!gameOver)
{
    Draw();
    Input();
    Logic();
    Sleep(100);
}
```

## 사용한 자료 구조

- `Point`: x, y 좌표를 묶은 구조체입니다.
- `tail[]`: 뱀 꼬리 각 칸의 좌표를 저장하는 구조체 배열입니다.
- `eDirection`: 멈춤·왼쪽·오른쪽·위·아래 상태를 표현하는 열거형입니다.

## Windows 콘솔 전용 코드

이 예제는 실시간 키 입력과 화면 갱신을 위해 Windows 전용 기능을 사용합니다.

- `<conio.h>`의 `_kbhit()`, `_getch()`
- `<windows.h>`의 `Sleep()`, 콘솔 커서 숨김 기능
- `system("cls")`의 콘솔 화면 지우기

따라서 Visual Studio의 Windows 콘솔 프로젝트에서 실행하는 수업 예제입니다.
