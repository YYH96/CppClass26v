# 파일 입출력(File I/O)

파일 입출력은 프로그램이 종료된 뒤에도 데이터를 남기거나, 다음 실행 때 다시 읽어 오는 기능입니다. C++에서는 `<fstream>` 헤더의 파일 스트림을 주로 사용합니다.

```cpp
#include <fstream>

std::ofstream outputFile; // 파일에 쓰기
std::ifstream inputFile;  // 파일에서 읽기
std::fstream file;        // 읽기와 쓰기 모두 가능
```

## 절대 경로

절대 경로는 드라이브 또는 루트부터 파일까지의 전체 위치를 적는 방식입니다.

```cpp
R"(C:\GameData\PlayerData.txt)"
```

Windows 경로의 `\`는 C++ 문자열에서 이스케이프 문자로 쓰이므로 `"C:\\GameData\\PlayerData.txt"`처럼 두 번 쓰거나, 위처럼 raw string(`R"(...)"`)을 사용합니다.

장점은 실행 위치가 바뀌어도 같은 파일을 가리킨다는 점입니다. 하지만 다른 컴퓨터에는 그 경로가 없을 수 있으므로, 게임 데이터 경로를 코드에 고정하는 방식은 보통 피합니다.

## 상대 경로

상대 경로는 **현재 작업 폴더(Current Working Directory)**를 기준으로 파일 위치를 적는 방식입니다.

```cpp
"PlayerData.txt"        // 현재 작업 폴더 안
"Data/PlayerData.txt"   // 현재 작업 폴더의 Data 폴더 안
"../PlayerData.txt"     // 한 단계 위 폴더
```

Visual Studio에서 디버그 실행할 때의 작업 폴더는 보통 프로젝트 폴더이지만, 프로젝트 속성에서 바꿀 수 있습니다. 파일을 찾지 못하면 먼저 `std::filesystem::current_path()`로 실제 작업 폴더를 출력해 확인합니다.

## 텍스트 파일 저장

텍스트 파일은 사람이 메모장으로 읽을 수 있는 문자 형태입니다.

```cpp
std::ofstream output("PlayerData.txt");
output << "이름\n";
output << 1000 << '\n';
```

`<<`로 저장하고, `>>` 또는 `std::getline`으로 읽습니다. 줄바꿈이나 쉼표처럼 데이터를 나누는 규칙을 저장할 때와 읽을 때 반드시 동일하게 정해야 합니다.

- `std::ios::app`: 기존 파일의 뒤에 이어서 쓴다.
- 기본 `ofstream` 열기: 기존 내용이 있으면 비우고 처음부터 쓴다.
- `is_open()` 또는 스트림 자체를 확인해 파일 열기에 실패했는지 검사한다.

## 바이너리 파일 저장

바이너리 파일은 값을 문자로 바꾸지 않고 바이트 그대로 저장합니다.

```cpp
std::ofstream output("PlayerData.bin", std::ios::binary);
output.write(reinterpret_cast<const char*>(&value), sizeof(value));
```

바이너리는 용량이 작고 빠를 수 있지만, 메모장의 글자로 읽을 수 없습니다. 또한 `std::string`처럼 내부에 포인터를 가진 객체를 `write(&object, sizeof(object))`로 통째로 저장하면 안 됩니다. 문자열은 **길이 → 실제 문자 데이터** 순서로 따로 저장하고, 읽을 때도 같은 순서로 복원해야 합니다.

컴파일러, 운영체제, CPU의 바이트 순서가 달라지면 같은 바이너리 파일을 그대로 읽지 못할 수 있습니다. 이 수업 예제는 같은 프로그램 환경에서 저장하고 읽는 기본 형식입니다.
