# CppClass26v

2026년 C++ 수업 자료와 예제 코드입니다. 각 프로젝트는 하나의 주제를 다루며, 처음 C++을 배우는 학습자가 코드와 주석을 함께 읽으며 실습할 수 있도록 구성했습니다.

## 실행 방법

한 프로젝트 안에는 여러 개의 `.cpp` 파일과 여러 개의 `main()` 함수가 있습니다. 한 번에 하나의 예제만 실행하도록, 실행하고 싶은 파일만 **빌드에서 제외**를 해제하고 나머지 파일은 빌드에서 제외합니다.

- 솔루션 탐색기에서 실행할 `.cpp` 파일을 우클릭합니다.
- **속성 → 구성 속성 → 일반 → 빌드에서 제외**를 `아니요`로 설정합니다.
- 나머지 `main()` 파일은 `예`로 설정한 뒤 빌드합니다.
