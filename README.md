# CppClass26v

2026년 C++ 수업 자료와 예제 코드입니다. 각 프로젝트는 하나의 주제를 다루며, 처음 C++을 배우는 학습자가 코드와 주석을 함께 읽으며 실습할 수 있도록 구성했습니다.

## 실행 방법

한 프로젝트 안에는 여러 개의 `.cpp` 파일과 여러 개의 `main()` 함수가 있습니다. 한 번에 하나의 예제만 실행하도록, 실행하고 싶은 파일만 **빌드에서 제외**를 해제하고 나머지 파일은 빌드에서 제외합니다.

- 솔루션 탐색기에서 실행할 `.cpp` 파일을 우클릭합니다.
- **속성 → 구성 속성 → 일반 → 빌드에서 제외**를 `아니요`로 설정합니다.
- 나머지 `main()` 파일은 `예`로 설정한 뒤 빌드합니다.

## 00_Theory — 개발 기초 이론

- 프로그램, 프로세스, 컴파일과 실행 과정을 정리한 `WhatIsProgram.MD`
- 헤더 파일과 `.cpp` 파일의 역할, 선언과 정의를 다룬 `HeaderAndCpp.MD`
- Visual Studio 기준 디버깅 방법과 주요 창을 정리한 `디버깅방법.MD`
- 주석, 코드 접기, 서식 등 자주 쓰는 단축키를 모은 `단축키.MD`
- x64와 x86 플랫폼, 버스, 캐시 적중률을 정리한 `x64와x86.MD`
- 전처리기와 매크로, 조건부 컴파일, Debug/Release 구성을 다룬 `01_PreprocessorAndMacro.cpp`

## 01_InputOutput — 입력과 출력

- `std::cout`, `std::cin`을 사용하는 기본 출력과 입력
- `printf`, `scanf`, `scanf_s`와 `stdio.h`의 관계
- 서식 지정자와 안전한 문자열 입력 예시

## 02_DataTypeAndConstant — 자료형과 상수

- 자료형을 “컴퓨터 메모리에 저장된 데이터를 해석하는 단위”로 이해하기
- 변수와 자주 쓰는 기본 자료형, 초기화
- 리터럴 상수와 `const` 상수
- 포인터 자료형과 참조 자료형의 기초
- 구조체, 열거형 등 사용자 정의 자료형 소개

## 03_Operators — 연산자

- 산술, 대입, 증감, 비교, 논리, 비트, 조건 연산자 등 기본 제공 연산자
- 0으로 나누기, 실수 비교 오차, 논리 연산의 단락 평가 등 주의점
- 연산자 오버로딩을 이용한 사용자 정의 연산자

## 04_Conditional — 조건문

- `if`, `else if`, `else`를 이용한 분기
- `switch` 문과 `case`, `break`, `default`
- 중첩 조건문과 삼항 연산자
- 입력한 메뉴에 따라 결과가 달라지는 커피 주문 실습 (`if` 버전, `switch` 버전)

## 05_Loop — 반복문

- `for`, `while`, `do while` 반복문
- `break`, `continue`의 흐름 제어
- 사각형, 직각삼각형, 피라미드, 다이아몬드, 마름모 별 찍기 실습
- 반복되는 커피 주문 실습과 `switch` 문 성적 출력 실습

## 06_Array — 배열

- 1차원 배열의 선언, 초기화, 인덱스와 포인터 연산 접근
- 문자 배열, 문자열, 널 문자(`\0`)
- 숫자 야구 게임 실습 — 배열과 중첩 반복문 활용
- 짝 맞추기 게임 실습 — 셔플 알고리즘과 배열 활용
- 빙고 게임 실습 — 함수 없이 `main()` 안에서 배열과 반복문으로 구현

## 07_Function — 함수

- 함수의 정의, 호출, 반환값, 매개변수와 함수 프로토타입 선언
- 자료형별 사칙연산 함수 오버로딩
- 일반 재귀와 꼬리 재귀 비교
- 팩토리얼과 피보나치 수열 재귀 실습
- 업다운 게임을 `main()`만 사용한 버전과 함수로 나눈 버전 비교
- 검 강화 게임 실습 — 함수 반환값, 참조 매개변수, `#define`, `std::pow` 활용

## 08_Struct — 구조체

- 구조체 선언, 멤버 접근, 초기화, 구조체 배열
- 구조체 멤버 함수와 연산자 오버로딩
- 메모리 정렬과 구조체 패딩

## 09_ScopeAndLifetime — 변수의 범위와 생명주기

- 지역 변수, 전역 변수, 정적 지역 변수의 범위와 생명주기
- 이름 충돌을 막는 네임스페이스와 범위 지정 연산자 `::`

## 10_Pointer — 포인터

- 주소 연산자 `&`, 역참조 연산자 `*`, `nullptr`, 포인터 자료형의 의미
- 배열과 포인터 연산, 배열을 포인터 매개변수로 전달하는 방법
- 구조체 포인터와 `->` 연산자
- `const int*`, `int* const`, `const int* const`의 차이
- `void*`, 함수 포인터, 포인터의 포인터 예제
- 배열을 함수 매개변수로 전달하는 빙고 게임 함수화 실습
