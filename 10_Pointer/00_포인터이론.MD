# 포인터 (Pointer)

수업 참고: [Notion - 포인터](https://app.notion.com/p/20d20618709880b5951ad1dfc94aeb4c)

## 포인터란?

포인터는 다른 변수나 객체가 저장된 **메모리 주소값**을 저장하는 변수입니다.

```cpp
int number = 10;
int* pNumber = &number;
```

위 코드에서 `number`에는 `10`이 저장되고, `pNumber`에는 `number`가 있는 주소가 저장됩니다. `pNumber`가 `number` 자체를 복사한 것이 아니라, `number`가 있는 위치를 알고 있는 것입니다.

`int*`의 `int`는 포인터가 저장한 주소를 어떤 자료형으로 해석할지 알려 줍니다. 즉, 포인터도 “주소에 있는 메모리를 해석하는 방식”이 필요합니다.

> !기억 - 포인터는 주소를 저장하고, 포인터의 자료형은 그 주소의 데이터를 어떻게 해석할지 정합니다.

## 꼭 알아둘 연산자

| 표기 | 이름 | 의미 |
| --- | --- | --- |
| `&number` | 주소 연산자 | `number`가 저장된 메모리 주소를 구함 |
| `*pNumber` | 역참조 연산자 | `pNumber`가 가리키는 주소의 값에 접근 |
| `object.member` | 멤버 접근 연산자 | 객체 자체의 멤버에 접근 |
| `pObject->member` | 화살표 연산자 | 포인터가 가리키는 객체의 멤버에 접근 |

```cpp
int number = 10;
int* pNumber = &number;

*pNumber = 50; // number가 저장된 위치의 값을 50으로 변경
```

`*pNumber = 50;` 이후에는 `number`의 값도 `50`입니다. 둘은 같은 메모리 공간을 보고 있기 때문입니다.

## 포인터의 크기

포인터는 주소 하나를 저장하므로, `int*`, `double*`, `Player*`처럼 가리키는 자료형이 달라도 같은 환경에서는 포인터의 크기가 같습니다.

- x64(64비트) 프로그램: 일반적으로 8바이트
- x86(32비트) 프로그램: 일반적으로 4바이트

반면 포인터가 가리키는 대상의 크기는 포인터 연산에 영향을 줍니다. `int* p`에서 `p + 1`은 1바이트 뒤가 아니라, 다음 `int` 요소의 주소를 뜻합니다.

## 포인터가 가리킬 수 있는 대상

- 기본 자료형 변수: `int*`, `double*`
- 구조체와 객체: `Player*`
- 배열의 요소: `int*`
- 함수: 함수 포인터
- 다른 포인터: `int**`

## 배열과 포인터

배열 이름은 대부분의 식에서 첫 번째 요소의 주소로 변환됩니다.

```cpp
int scores[3] = { 10, 20, 30 };
int* pScore = scores;

scores[1];       // 20
*(pScore + 1);   // 20, 위 코드와 같은 요소
```

배열과 포인터가 완전히 같은 것은 아닙니다. 배열은 여러 값을 실제로 보관하는 공간이고, 포인터는 주소 하나를 보관하는 변수입니다. 특히 함수에 배열을 전달하면 포인터로 바뀌므로 배열의 크기를 함께 전달해야 합니다.

## 안전하게 사용하는 규칙

- 포인터는 선언과 동시에 유효한 주소 또는 `nullptr`로 초기화합니다.
- `nullptr`인지 확인한 뒤에만 역참조합니다.
- 배열 범위 밖으로 이동하거나 역참조하지 않습니다.
- 값만 읽을 함수에는 `const int*`처럼 `const`를 사용해 변경을 막습니다.
- `void*`는 자료형 정보가 없으므로 필요한 경우에만 쓰고, 사용 전 올바른 자료형 포인터로 변환합니다.

```cpp
int* pNumber = nullptr;

if (pNumber != nullptr)
{
    std::cout << *pNumber;
}
```

## 이 프로젝트의 학습 순서

1. 주소와 역참조, `nullptr`
2. 배열과 포인터 연산
3. 포인터를 함수 매개변수로 전달하기
4. 구조체 포인터와 `->`
5. `const`가 붙은 포인터
6. `void*`, 함수 포인터, 포인터의 포인터

함수 포인터 예제에서는 같은 버블 정렬 함수에 오름차순·내림차순 비교 함수를 각각 전달합니다. 정렬 알고리즘은 바꾸지 않고, 함수 포인터로 비교 기준만 교체하는 방식입니다.

`this` 포인터와 멤버 포인터는 클래스 수업에서 다룹니다. 포인터의 핵심은 “주소를 안전하게 저장하고, 올바른 자료형으로 해석하여 원본 데이터에 접근한다”는 점입니다.
