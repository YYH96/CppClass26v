# 클래스와 vector로 만드는 스네이크 게임

17번 프로젝트는 한 파일에서 게임의 전체 흐름을 먼저 살펴보는 예제입니다.  
19번 프로젝트는 같은 게임을 역할별 클래스로 나눈 예제입니다.

## 역할 분리

- `CGameManager`: 게임 시작, 입력, 화면 출력, 충돌 검사, 전체 게임 루프를 관리한다.
- `CSnake`: 뱀의 몸통 위치와 이동 방향을 관리한다.
- `CApple`: 사과의 위치와 재생성을 담당한다.
- `GameInfo.h`: 좌표 구조체, 방향 열거형, 게임판 크기처럼 함께 쓰는 정보를 모아 둔다.

## vector가 쓰이는 곳

`CSnake`는 몸통의 모든 좌표를 `std::vector<POS>`에 저장합니다.

```cpp
std::vector<POS> mSnake;
```

사과를 먹을 때 `push_back`으로 꼬리를 한 칸 늘리고, 이동할 때는 뒤쪽 원소부터 앞 원소의 좌표를 복사합니다. 몸통 길이가 실행 중에 늘어나므로 일반 배열보다 vector가 잘 어울립니다.

## 실행 방법

- `W`, `A`, `S`, `D`: 위, 왼쪽, 아래, 오른쪽 이동
- `X`: 게임을 종료한다.
- 벽 또는 자기 몸통에 닿으면 게임 오버다.

Windows 콘솔 전용 예제이며 `_kbhit`, `_getch`, `Sleep`, `system("cls")`를 사용합니다.
