# 빙고 게임 클래스화

이 프로젝트는 이전에 `main()` 하나에 작성하던 빙고 게임을 역할별 클래스로 나눈 예제입니다.

## 클래스 역할

- `CObject`: 빙고판 생성·셔플·숫자 표시·빙고 줄 계산처럼 플레이어와 AI가 공통으로 쓰는 기능을 가진 부모 클래스
- `CPlayer`: 사람 플레이어를 나타내는 자식 클래스
- `CAI`: AI 플레이어를 나타내는 자식 클래스. 남은 숫자 중 하나를 무작위로 선택한다.
- `CGameManager`: 게임 루프, 입력, 출력, 승패 확인을 담당하는 싱글턴 클래스

## 적용한 C++ 개념

- `std::vector<int>`로 25칸 빙고판과 객체 목록을 관리한다.
- `CObject*`로 자식 객체를 한 컨테이너에 보관한다.
- 가상 소멸자를 둔 부모 클래스에서 `dynamic_cast`로 `CPlayer*`, `CAI*`를 얻는다.
- `enum class`를 객체 종류·게임 결과로 사용한다.
- `new`로 만든 플레이어와 AI는 `Release()`에서 `delete`한다.

## 규칙

- 1~25 중 하나를 입력한다.
- 이미 표시한 숫자나 범위를 벗어난 값은 다시 입력한다.
- `0`을 입력하면 게임을 종료한다.
- 플레이어 또는 AI가 5줄 이상 빙고를 만들면 승패가 결정된다.
